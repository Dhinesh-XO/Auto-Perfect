# Evidence and confidentiality

## What this repository establishes

This repository records the scope of Dhinesh Kannan's professional contribution to a Piper-X autonomous-manipulation project and identifies the public technologies involved.

It is a professional case study, not a reproducibility package. The implementation was developed in an employment environment, so publication is deliberately limited to non-confidential descriptions.

## Included

- A concise account of personal responsibilities
- Publicly known technology names
- A newly written, high-level workflow diagram
- Links to public upstream resources and research
- Clear statements about experimental scope and limitations

## Excluded

- Employer source code and Git history
- Internal architecture and configuration
- Prompts, policies, model files, and private dependencies
- Raw logs, datasets, evaluation outputs, and recordings
- Screenshots containing internal project paths or private workspaces
- Company hardware photographs and demonstration videos
- Credentials, network details, device identifiers, and personal data
- Quantitative performance claims that cannot be publicly substantiated

## Validation boundary

No internal log, screenshot, video, or dataset found on the development workstation is published here. Their presence was used only to avoid unsupported statements and to separate hardware work from software-only or experimental work.

Readers should not interpret this repository as independent reproduction of the employer system, ENPIRE, or a certified autonomous manipulation platform.
